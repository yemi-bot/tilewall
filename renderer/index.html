Tilewall

Paste one or more links. Each one gets its own tile, and its video fills the tile like it is fullscreen.

Enter to add. Shift+Enter for a new line.
  • Ctrl 1-9 picks which tile you hear
  • Hover the top edge of a tile for its controls. Hover the bottom edge of the window for the toolbar.
  • F11 fullscreen. F1 all shortcuts.

Shortcuts

Ctrl N
Add links
Ctrl 1-9
Hear tile 1-9 (it also becomes the big tile in Focus and Solo)
Ctrl M or Ctrl 0
Mute all / unmute
Ctrl Shift M
Sound follows your mouse
Ctrl Alt 1-9
Same as Ctrl+1-9, but works while you are in another app (a game, a browser)
Ctrl Alt → / ←
Next / previous tile, from any app (inside Tilewall also Ctrl Tab)
Ctrl Alt M / F / L
Mute all, one tile only, switch layout - from any app
Ctrl L
Switch layout: Grid, Focus, Solo
Ctrl F
Show one tile only, press again to go back
Ctrl H
Hide all controls for a clean wall
Ctrl R
Reload the tile you are hearing (Shift reloads all)
F11
Fullscreen
Hold Ctrl
Show tile numbers

Stay live (toolbar): a live stream that falls behind jumps back to live. If you rewind on purpose it waits until you are back. Hover the top edge of a tile for its controls. Drag the dots to move a tile. Right-click inside a tile for back, reload and open in your browser.
